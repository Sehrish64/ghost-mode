# Ghost Mode — Tracker Blocker & Site Wiper (MV3)

Honest privacy extension:
- **Tracker blocking** — 26 major trackers (Google Analytics, Meta Pixel, Hotjar, Clarity, TikTok Analytics...) blocked via declarativeNetRequest, with a live counter in the popup.
- **POOF button** — one click wipes the current site's cookies + local storage + cache + IndexedDB from YOUR browser (chrome.browsingData).
- **Auto-wipe** — when ON, closing a tab wipes that site's data automatically and shows a notification.
- **Fake browser identity** — optional User-Agent switch (looks like Firefox to sites).

What it does NOT do (and no extension can): delete data already stored on a website's server (profile visits, IP logs, analytics history). Anyone claiming that is lying.

## Install (free, no Web Store needed)
1. Unzip this folder.
2. Open chrome://extensions in Chrome.
3. Turn ON "Developer mode" (top right).
4. Click "Load unpacked" and select this folder.
5. Pin the ghost icon and browse — open the popup on any site and hit POOF.

Publishing on the Chrome Web Store is optional and costs a one-time $5 developer fee.
